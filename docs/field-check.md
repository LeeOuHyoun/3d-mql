## 0.0.40 변경 (편집 창 속성 정보 조회 개선)

편집 창이 속성마다 `print attribute` 를 따로 실행해 속성이 많은 객체에서 1분 넘게 "불러오는 중..." 이 이어지던 문제를 줄였습니다. 속성 정보를 `list attribute "A,B,…" select type default range` 한 번으로 묶어 조회하고, 결과는 속성 이름별로 기억합니다. 묶음 조회가 실패하거나 결과에 빠진 속성만 예전처럼 `print attribute` 로 하나씩 조회합니다. 가짜 MQL로만 확인했습니다.
- [ ] ⚠️ 속성이 많은 객체에서 편집을 누르면 출력 로그에 `list attribute "…" select type default range` 가 한 번 찍히고, 그 응답에 `attribute <이름>` 줄과 `type = …` 줄이 속성마다 나온다 (실제 MQL 출력 형식 확인)
- [ ] ⚠️ 편집 창이 예전보다 빨리 열리고, 선택지(range)가 있는 속성은 목록으로, boolean 속성은 TRUE/FALSE 로 나온다
- [ ] 같은 type의 다른 객체를 편집하면 `list attribute`·`print attribute` 없이 바로 열린다
- [ ] 상세 패널에 정보가 떠 있는 객체를 편집하면 `print bus` 를 다시 실행하지 않는다
- [ ] 콘솔에서 `mod attribute …` 를 실행한 뒤 편집을 열면 속성 정보를 새로 조회한다

## 0.0.39 변경 (MQL 중복 실행 방지)

버튼을 연달아 눌러도 같은 MQL이 여러 번 실행되지 않게 했습니다. 실행 중인 같은 동작은 새로 보내지 않고 앞 결과를 함께 씁니다. 가짜 백엔드로만 확인했습니다.
- [ ] ⚠️ 상세 패널의 Expand (From)·Where Used (To) 를 빠르게 여러 번 눌러도 expand 가 한 번만 실행된다 (출력 로그 확인). 실행 중에는 두 버튼과 툴바 새로고침 버튼이 흐리게 잠긴다
- [ ] 노드 더블클릭·우클릭 펼치기를 연타해도 그래프가 한 번만 다시 그려진다
- [ ] ⚠️ 펼치기가 끝나기 전에 다른 객체를 기준으로 열거나 그래프를 지우면, 늦게 끝난 펼치기 결과가 새 그래프에 섞이지 않는다
- [ ] 새로고침 도중 펼치기를 누르면 새로고침이 끝난 뒤 펼쳐지고, 새로고침 결과에 그 노드가 "삭제"로 잘못 표시되지 않는다
- [ ] 펼치기 두 개를 동시에 돌리면 둘 다 끝날 때까지 툴바 스피너가 계속 돈다
- [ ] 우클릭 메뉴의 조회 실행(run)·삭제 문장 담기를 연타해도 콘솔 실행·바구니 담기가 한 번만 일어난다
- [ ] ⚠️ 콘솔에서 `print`·`temp query` 같은 조회만 실행한 뒤 노드를 누르면 상세 정보가 바로 뜬다 (다시 조회하지 않음). `mod`·`set context` 같은 명령을 실행한 뒤에는 상세 정보를 새로 조회한다

## 0.0.35 변경 (콘솔 문법 색칠)

MQL 콘솔의 입력창과 기록의 명령 문장에 문법 색을 넣었습니다 (enovia-mql 0.0.24 와 같은 규칙). 입력창은 글자를 투명하게 하고 같은 위치에 색칠한 글자를 겹쳐 그립니다. 헤드리스 브라우저로만 확인했습니다.

- [ ] ⚠️ 콘솔 입력창에 입력하면 명령어(temp · print · mod …)는 보라, 키워드(bus · select · where …)는 파랑, 따옴표 값은 초록, ID · 숫자는 주황, `attribute[…]` 같은 select 식은 청록, 템플릿의 `<…>` 칸은 노랑 점선으로 보인다
- [ ] ⚠️ 커서 위치 · 글자 선택 · 한글 입력(조합 중 글자 포함)이 글자와 어긋나지 않는다. 긴 줄이 접히거나 입력창을 스크롤해도 어긋나지 않는다
- [ ] 입력창이 비어 있을 때 안내 문구(MQL 명령 입력 …)가 예전처럼 흐린 글씨로 보인다
- [ ] 입력창 높이를 끌어 바꾸거나 콘솔을 전체 화면으로 바꿔도 색칠한 글자가 제자리에 있다
- [ ] 기록의 `MQL>` 뒤 명령 문장도 같은 색으로 보인다
- [ ] 자동완성 목록 · Tab 으로 `<…>` 칸 이동 · Ctrl+Shift+F 포매팅이 예전처럼 동작한다
- [ ] 2만 자가 넘는 긴 스크립트를 붙여 넣으면 색칠 없이 보이고 입력이 느려지지 않는다

## 0.0.34 변경 (버벅임 개선 · 전체 검토 수정)

전체 검토로 찾은 오류를 고치고, 버벅이던 원인을 브라우저에서 재서 줄였습니다. 노드 600개 · 화면 배율 200% 기준으로 클릭 · 패널 열기 · 펼치기 때 생기던 50~90ms 멈춤이 사라졌습니다. 헤드리스 브라우저와 가짜 MQL 로만 확인했습니다.

### A. 상세 패널 자동 열기

- [ ] 화면 오른쪽 끝의 노드를 클릭해 패널이 열리면, 그 노드가 패널에 가려지지 않도록 화면이 부드럽게 옮겨진다
- [ ] 패널을 닫은 뒤 펼치기 · 새로고침 · 관계 필터 변경처럼 클릭이 아닌 동작으로는 패널이 다시 열리지 않는다
- [ ] 드래그로 여러 개를 고르거나 빈 곳을 클릭하면 패널이 열리지 않는다
- [ ] 창을 닫았다 다시 열었을 때(복원) 패널을 닫아 둔 상태였다면 닫힌 채로 남는다

- [ ] ⚠️ 롤백 스크립트를 실제로 실행하면 원래 상태로 돌아온다 (연결 해제 → 재연결 시 관계 속성 값이 복원되는지)
- [ ] 번개 아이콘을 누르면 그 문장이 실행할 트리거가 보인다 (promote → Promote…, connect → Create…)
- [ ] ⚠️ "트랜잭션으로 미리보기" 를 누르면 그래프 위에 Commit · Abort 가 뜨고, 변경 결과가 그래프에 표시된다. Abort 하면 원래대로 돌아오고 문장은 다시 대기 상태가 된다
- [ ] ⚠️ 미리보기 중 120초가 지나면 자동으로 abort 된다. 카운트다운은 문장 실행이 모두 끝난 뒤부터 줄어든다
- [ ] ⚠️ 문장이 실행되는 도중에 Abort 를 누르면 남은 문장은 실행되지 않고 전부 원복된다. Commit 을 누르면 그때까지 실행된 문장만 반영되고 나머지는 대기로 남는다

- [ ] 미리보기 중 다른 사용자의 같은 객체 작업이 막히지 않는지 (DB 잠금)

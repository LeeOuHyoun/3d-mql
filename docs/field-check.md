## 1. MQL 연동 확장 (0.0.19 ~ 0.0.20)

0.0.19 이후의 기능은 사양서에 없는 MQL 문법과 출력 형식을 일부 가정하고 만들었습니다.
1-1을 먼저 확인해 주세요. 1-1에서 어긋난 항목이 있으면 그 문법에 기대는 기능(괄호 안)은 동작하지 않습니다.

### 1-1. MQL 문법 · 출력 형식 사전 확인

MQL 콘솔에서 직접 실행합니다. 결과가 설명과 다르면 `피드백:`에 실제 출력을 붙여 주세요.

- [ ] ⚠️ `print context;` 출력이 `context vault <vault> user <user>` 꼴이다 (하단 바 접속 표시, 스크립트 머리말의 Create by)
- [ ] ⚠️ `temp query bus <Type> * * limit 5 where "current=='<State>'" select id current dump |;` 가 실행된다 — `limit` 뒤에 `where`가 오는 순서 (Where 검색)
- [ ] ⚠️ `expand bus <id> from relationship * select bus type id current where "current=='<State>'" select rel type id dump |;` 가 실행되고 조건에 맞는 객체만 나온다 (Expand 옵션의 객체 Where)
- [ ] ⚠️ `expand bus <id> from relationship * select bus type id current select rel type id where "<관계 속성 조건>" dump |;` 가 실행된다 (Expand 옵션의 관계 Where)
- [ ] `recurse to 3`에 객체 Where를 함께 줬을 때, 조건에 안 맞는 중간 객체의 하위가 결과에서 빠지는지 남는지 (피드백에 적어 주세요)
- [ ] ⚠️ `expand bus <id> to relationship * recurse to end select bus type id current select rel type id dump | limit 20;` 이 말단(최상위) 객체만 돌려준다. 첫 칸의 단계 숫자가 무엇으로 나오는지도 적어 주세요 (Recurse "말단만")
- [ ] `expand bus <id> from relationship * recurse to all select bus type id current select rel type id dump | limit 20;` 이 실행된다 (Recurse "끝까지")
- [ ] ⚠️ 이름에 공백이 있는 관계로 `print bus <id> select "from[<관계 이름>].to.id";` 처럼 select 식 전체를 따옴표로 감싸도 값이 나온다 (경로 select 식의 print 문장)
- [ ] ⚠️ `print bus <id> select from[<관계>].to.to[<관계>].from.id;` 처럼 여러 단계를 이은 식이 값을 돌려준다 (경로 select 식)
- [ ] ⚠️ `delete connection <connection id>;` 문법이 맞다 — 테스트용 연결로 확인 (연결 해제 문장)
- [ ] ⚠️ `add connection "<관계>" from <id> to <id> "<속성>" "<값>";` 처럼 속성 값을 같은 문장에 줄 수 있다 (연결 해제의 되돌리는 문장)
- [ ] `add connection "<관계>" fromrel <connection id> to <id>;` 문법이 맞다 (끝점이 connection인 연결의 되돌리는 문장)
- [ ] `modify connection <connection id> "<속성>" "<값>";` 문법이 맞다 (관계 속성의 값 수정 문장)
- [ ] `modify bus <id> description "<값>";` 과 `modify bus <id> owner "<사용자>";` 문법이 맞다 (값 수정 문장)
- [ ] ⚠️ `print bus <id> select state.actual;` 출력이 `state[<상태>].actual = <일시>` 꼴이다 (States 탭의 진입 일시)
- [ ] ⚠️ `print bus <id> select state.signature.satisfied;` 출력이 `state[<상태>].signature[<서명>].satisfied = TRUE` 꼴이다 (States 탭의 서명)
- [ ] ⚠️ `print bus <id> select current.access;` 출력이 `current.access = read,modify,...` 꼴이다 (Access 표시)
- [ ] ⚠️ creator에서 `push context user <다른 사용자>; print bus <id> select current.access; pop context;` 가 암호 없이 실행된다 (다른 사용자의 access 확인)

## 1. MQL 콘솔 개선 (0.0.18)

### 1-1. 결과 표 보기
- [ ] ⚠️ `temp query bus <type> * * select id current dump;` 결과가 표로 바뀌고, 열 제목이 `type / name / revision / id / current`로 맞게 나온다
- [ ] ⚠️ 구분자를 지정한 `... dump |;` 결과도 표로 바뀐다
- [ ] ⚠️ 값 안에 구분자(`,` 등)가 들어 있는 결과에서 열이 밀리지 않는다 (밀리면 피드백)
- [ ] `print bus <id> select current id attribute[...];` 결과가 `key / value` 표로 나온다
- [ ] 여러 객체를 select한 결과(`temp query bus ... select ...` dump 없이)가 객체마다 한 행으로 나온다
- [ ] 값이 여러 줄인 항목이 한 칸 안에 줄바꿈되어 나온다
- [ ] 표로 바꿀 수 없는 결과(`list type;` 등)에는 표 버튼이 나오지 않는다
- [ ] 표 상태에서 복사한 내용을 엑셀에 붙여 넣으면 칸이 맞게 들어간다

피드백:

### 1-2. 결과 속 Object ID 메뉴
- [ ] 결과(텍스트·표 모두)의 Object ID에 점선 밑줄이 보이고, 클릭하면 메뉴가 뜬다
- [ ] "그래프에서 열기"를 누르면 해당 객체가 기준 객체로 그래프에 열린다
- [ ] 콘솔 전체 화면 상태에서 "그래프에서 열기"를 누르면 전체 화면이 풀리고 그래프가 보인다
- [ ] print bus / expand bus (from·to) 실행 결과가 그래프 우클릭 메뉴로 실행한 것과 같다
- [ ] Object ID 복사가 된다

피드백:

### 1-4. 결과 내 찾기

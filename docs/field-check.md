트랜잭션 · 세션

- [ ] ⚠️ 콘솔 명령은 출력 없이 60초가 넘어도 끊기지 않는다. 실행 중인 항목 머리의 빨간 ■ (실행 중단) 으로 끊을 수 있고, 트랜잭션 중이면 중단 전에 확인 창이 뜬다
- [ ] ⚠️ 그래프 조회가 60초 동안 응답하지 않을 때 트랜잭션 중이면 다시 연결하기 전에 확인 창이 뜨고, 취소하면 계속 기다린다
- [ ] ⚠️ 콘솔에서 `set context user <다른 사용자> …;` 로 바꾼 뒤 시간 초과 · 실행 중단으로 다시 연결되면 그 사용자로 복구되고 `verb on;` 도 다시 켜진다. 하단 바 `MQL 재연결` 은 설정의 접속 명령으로 새로 접속한다
- [ ] ⚠️ States 탭 Promote · 서명 버튼, 콘솔 항목의 다시 실행, 명령 기록 더블클릭을 빠르게 두 번 눌러도 같은 명령은 한 번만 실행된다
- [ ] Promote · Demote 툴팁에 다음 · 이전 state 가 보이고, 마지막 · 첫 state 에서는 버튼이 잠긴다

콘솔 결과
- [ ] ⚠️ 그래프에서 바로 실행한 삭제 · 연결 해제 · 편집 · Demote 결과 아래에 되돌리는 문장(삭제는 다시 만드는 문장)과 입력창에 넣기 · 복사 버튼이 붙는다
- [ ] `set context user <사용자> password <비밀번호>;` 를 실행하면 콘솔 항목에 `password ****` 로 보이고 다시 실행 버튼이 없다. 명령 기록 · 저장에도 남지 않는다. 따옴표 안의 password 글자는 가리지 않는다

- [ ] 찾기에 단어 단위(ab) 옵션이 생기고, 명령 줄과 접힌 항목 안도 찾는다 (접힌 항목은 찾는 동안 펼쳐 보임)

콘솔 입력
- [ ] 콘솔 입력창에 커서가 있을 때 Ctrl+J 로 줄이 합쳐진다. 그 밖의 곳에서는 VS Code 의 Ctrl+J 가 그대로 동작한다
- [ ] 입력창이 내용에 맞춰 92px 부터 콘솔 높이 절반까지 자동으로 늘어난다. 위 막대를 끌면 그 높이로 고정되고, 더블클릭하면 자동으로 돌아간다

- [ ] 입력창에 `# owner's note` 처럼 `'` 가 든 주석 줄이 있어도 Ctrl+Enter 로 커서가 있는 문장만 실행된다 (전에는 주석 아래 문장이 한꺼번에 실행됐음)
- [ ] ⚠️ 명령 뒤 줄 끝에 주석을 달 수 있다: `print bus <id>; # 메모` 또는 `print bus <id> # 메모`. 주석은 회색으로 보이고 MQL 로는 보내지 않으며 콘솔 항목 · 명령 기록에도 주석 없이 남는다. `;` 가 없으면 주석 앞에 들어간다

- [ ] 포매팅 뒤에도 주석이 원래 단어 뒤 줄 끝에 남는다. 주의: 따옴표 없이 `dump #` 처럼 `#` 를 값으로 쓰면 주석으로 보므로 `dump '#'` 로 쓴다

## 0.0.50 (심볼릭 이름 하나씩 조회 · 줄 번호 버튼)

심볼릭 이름 표시는 설정 없이 항상 켜져 있고, 전체 대응표 대신 `list property to <type> "<이름>"` 으로 필요한 이름만 조회합니다. 하단 바의 설정(톱니바퀴) 메뉴는 없어지고, 줄 번호 버튼은 MQL Console 헤더로 옮겼습니다.
- [ ] ⚠️ 노드를 선택하면 Properties 탭의 Type · Policy · Vault 아래에 심볼릭 이름(`type_…` 등)이 바로 나오고, 출력 로그에 `list property to …` 가 짧게 찍힌다. History · States · Triggers 탭과 콘솔은 느려지지 않는다
- [ ] 속성(Attributes) 값을 우클릭하면 잠시 뒤 "심볼릭 이름 복사" 항목이 생기고, 누르면 `attribute_…` 가 복사된다
- [ ] MQL Console 헤더의 줄 번호 버튼(찾기 · 명령 기록 버튼 사이)을 켜면 입력창에 줄 번호가 나온다. 긴 줄이 줄바꿈돼도 번호가 맞고, 스크롤하면 함께 움직이며, 창을 다시 열어도 유지된다
